# 错词字典模板（用户自填）

即兴 / 半即兴口播没有逐字稿时，用这份字典告诉 ASR 哪些专名容易被识别错。`qiushuiai-asr` 在出字幕后会**逐条对照替换**。

## 格式

每行一条，左边是**常见误识别**，右边是**正确写法**，用 `→`（或 `->` / `=>`）连接。`#`、`>`、表格、代码围栏行会被忽略，所以本文件可直接当字典传给 `--dict`。

```
误识别 → 正确
```

## 示例（按需改成你自己的）

乘风 → 成峰
正特 → Agent
克劳德扣的 → Claude Code
cloud code → Claude Code
敏猫 → MiniMax
抖音豆包 → 豆包

## 怎么用

```bash
--dict <vault>/01-账号/错词字典.md
```

把这份文件复制到 vault 的 `01-账号/` 下（一份字典复用所有视频），常踩的专名错误持续往里加。也可在 CONFIG.md 里设 `dict:` 默认路径，免得每次传。

## 与口播稿的区别

| | 照稿念（--script 口播稿） | 错词字典 |
|---|---|---|
| 准确率 | 最高（字幕直接用稿子文本） | 95%+ |
| 适用 | 照 `script.md` 念的内容 | 即兴 / 半即兴 |
| 维护 | 每条视频一份稿 | 一份字典复用 |

两者可叠加：有口播稿走口播稿，字典作兜底纠错。
