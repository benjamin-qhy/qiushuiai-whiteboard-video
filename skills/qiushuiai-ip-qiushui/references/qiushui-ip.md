# Qiushui IP

## 角色定义

qiushui 是 qiushuiai 中文正文配图的新固定视觉 IP。

默认每张图都要出现 qiushui。它不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转的冷面知识工作者。在配图里它是“参与的配角”，不是抢镜的主角。默认每张图至少要有 qiushui 一人；如果对应文案确实需要人际关系场景，可以再加入次要人物，但不能把 qiushui 替换掉。

例外：白板视频配图或用户明确要求“奇数用参考图、偶数用美女”时，启用编号交替人物模式。奇数图仍使用 qiushui；偶数图默认由一位漂亮、专业、认真工作的职场女性 / 女性知识工作者替代 qiushui 成为人物主角。偶数图只有在文案确实需要多人关系时才加入 qiushui；只要 qiushui 出现，他必须使用参考头像身份，并作为画面中的人物主角参与核心动作，不能被画成路人、背景人或弱配角。

## 身份来源优先级

### 1. 有参考头像时

- 参考头像是人物身份的最高优先级来源。
- 必须尽量保留同一张脸的识别特征：发型、眼镜、脸部结构、肤色、整体气质。
- 不要把参考头像重设计成“差不多”的新角色。
- 允许身体、服装、动作、比例按正文配图风格做简化和适配。

### 2. 无参考头像时

- 用默认文字设定生成 qiushui。
- 默认气质：冷静、认真、克制、略带荒诞感的知识工作者 / 系统操作员。
- 默认脸部特征：深色整齐头发、细圆框眼镜、平静严肃的表情、干净利落的脸部结构。

## 外形

- 大头小身体，头部识别度优先于身体细节。
- 如果用了参考头像，头和脸优先贴近参考图；不要强行替换成橙色圆头。
- 身体使用简单手绘的休闲商务装角色语言：合身的长袖或短袖上衣、针织衫、Polo、衬衫或轻商务 T 恤都可以，颜色克制、线条简单。
- 轮廓要有一点手绘抖动和草图感，不要太商业、太 3D、太精致。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个低调的系统操作员 / 内容工人 / 知识工作者。
- 冷幽默，不卖萌。
- 有点笨拙，但不蠢。
- 像在白板草图里真的负责某个工作。

## 常见职责

让 qiushui 承担核心动作（但画小、放一侧，不要抢镜）：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作“判断”杆。
- 当筛选漏斗的操作员。
- 切开素材。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞里伸手但接不住内容。
- 在旁边搬砖、搭桥、开门、分拣、记录。

## 与其他人物的关系

- qiushui 是固定 IP 锚点，不是唯一允许出现的人物。
- 如果文案在讲交流、陪伴、协作、社群、信任、客户、用户、现场互动等关系，可以加入 1 个或多个次要人物。
- 这些次要人物默认作为场景配角存在，用来承接关系，不是新的主角。
- 即使是多人场景，第一优先级仍然是结构信息，第二优先级是 qiushui，其他人物排在后面。
- 如果额外人物的加入不能提升这张图对文案的表达，就不要加。

## 弱化原则

qiushui 是配图的参与者，不是封面主角：

- 画小：身高大约只占画面高度的 1/5～1/4，放在画面一侧，不占正中央。
- 让位：第一眼被看到的必须是表达概念的结构和物件，qiushui 只是小小地参与其中。
- 颜色克制：人物身上的暖色点缀要少；流程/箭头用更深更纯的橙，避免人物和功能色撞色。

## 禁止

- 不要把 qiushui 画成过度可爱的吉祥物。
- 不要画成儿童卡通角色。
- 不要给 qiushui 复杂服装、表情包、闪亮眼睛。
- 严禁让 qiushui 穿西装外套、夹克、风衣、大衣或任何外套类服装。
- 不要让 qiushui 太大、太居中、盖过结构信息。
- 不要让 qiushui 只是站在角落里看而不参与动作。
- 不要把 qiushui 画得太商业、太圆润、太精致、太 3D。
- 不要在用了参考头像时把人物改成另一张脸。
- 不要把新增人物画得比 qiushui 更大、更亮、更居中。
- 不要把画面做成美女海报、人物群像海报或社交平台写真感插画。

## 判断标准

如果去掉 qiushui，图的核心隐喻还能完全成立，说明 qiushui 太装饰了；要重写提示词，让 qiushui 真正参与动作。
反过来，如果第一眼先看到的是 qiushui 而不是结构信息，说明 qiushui 太抢镜了；要把它画小、移到一侧。
如果加入其他人物后，第一眼先看到的是她们而不是结构和 qiushui，说明配角过强了；要缩小、弱化、移边，或直接删掉。
